# AE2 Graph Crafting

[English](README.md) | **Русский**

Аддон для Applied Energistics 2 **rv3-beta-6** (Minecraft 1.7.10). Мод является coremod'ом и встраивается в классы AE2.

CPU крафта с графовым со-процессором планирует весь заказ сразу по всем паттернам сети. Он выбирает самую дешёвую комбинацию рецептов, пускает побочные продукты одних шагов в другие и использует циклы переработки, если они экономят ресурсы. Стандартный AE2 выбирает один рецепт на предмет и не учитывает побочки.

## Требования

- Minecraft 1.7.10, Forge 10.13.4.1614
- Applied Energistics 2 rv3-beta-6

Ставится и на клиент, и на сервер.

## Предметы

### Графовый со-процессор

Часть мультиблока CPU крафта, ставится как обычный блок крафта. CPU с со-процессором выполняет графовый план, остальные CPU выполняют стандартный план AE2. Если со-процессоров в сети нет, мод ничего не меняет.

Также работает как ускоритель крафта (+64 по умолчанию, `coprocessorAcceleration`).

ПКМ открывает граф текущего или последнего плана: слева сырьё, справа цель, фиолетовые узлы — паттерны, оранжевые дуги — циклы. Shift + ПКМ пустой рукой открывает обычный статус CPU.

```text
E C E    E - инженерный процессор
L X L    C - вычислительный процессор
E C E    L - логический процессор
         X - сопроцессор создания
```

### Карта ускоренной подачи

Улучшение для МЕ-интерфейса (блок или панель). Обычно, если машина приняла паттерн не целиком, интерфейс на несколько секунд перестаёт брать следующие. С картой CPU подаёт паттерны в машину без пауз.

```text
E P E    E - инженерный процессор
A S A    P - изменчивая жемчужина
E P E    A - продвинутая карта
         S - карта ускорения
```

### Шина удалённого крафта

Позволяет одной МЕ-сети заказывать крафты у другой, не объединяя их. Шина ставится в сеть A и смотрит на МЕ-интерфейс сети B. Крафты этого интерфейса появляются в терминалах сети A. Сеть B считает и выполняет их на своих CPU своими ресурсами, а шина передаёт результат в сеть A.

Если сети B не хватает ресурсов на заказ, шина один раз за заказ переносит в неё из хранилища сети A ровно недостающее. Паттерны, хранилище и цепочку крафта сети B сеть A не видит: она отдаёт сырьё и получает результат.

Машины сети B должны возвращать результат в сеть B (в её интерфейс или шину импорта сети B), а не в сеть A. Иначе CPU сети B его не увидит, и шина предупредит об этом в своём окне.

Кнопка **«Приоритет»** в интерфейсе шины:

- **ВКЛ**: эти предметы крафтятся только через шину. Собственные паттерны сети A для них игнорируются.
- **ВЫКЛ**: сеть A сначала использует свои паттерны, сеть B докрафчивает остальное.

```text
E P E    E - инженерный процессор
S I S    P - изменчивая жемчужина
E P E    S - шина хранения
         I - МЕ-интерфейс (панель)
```

## Прочие изменения

Работают на всех CPU крафта, с со-процессором и без:

- Предметы, которые не нужны оставшимся шагам, сразу уходят в ME, а не ждут конца задачи.
- Если задача не двигается 60 секунд, CPU берёт недостающее из ME. Если цель уже выдана, задача закрывается и CPU освобождается.

Если граф не может построить план, используется план AE2, а в чат пишется причина.

## Настройки

`config/aegraph.cfg`. Команда: `/aegraph status|on|off|log|reload` (только для op).

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `enabled` | true | Включить мод |
| `requireCoprocessor` | true | Если false, графовый план используют все CPU |
| `coprocessorAcceleration` | 64 | Ускорение от графового со-процессора |
| `fallbackToAE2WhenMissing` | true | Брать план AE2, если графу не хватает предметов, а AE2 хватает |
| `returnUnneededItems` | true | Сразу отправлять в ME предметы, не нужные шагам |
| `stallSeconds` | 60 | Секунд без движения до восстановления задачи, 0 — выключить |
| `substitutes` | true | Паттерны верстака с включённой заменой могут брать равноценные предметы |
| `fluidCostPerMb` | 0.001 | Цена 1 mB жидкости |
| `storedIntermediateFactor` | 0.9 | Множитель цены для скрафченных предметов, уже лежащих в ME |
| `surplusPenalty` | 0.01 | Штраф за оставшиеся побочки |
| `stockFirstTolerance` | 0.05 | Насколько план может быть хуже ради расхода накопленных полуфабрикатов, 0 — выключить |
| `remoteCraftCost` | 100 | Цена крафта через шину удалённого крафта с выключенным приоритетом |
| `itemCostOverrides` | | `modid:name[@meta]=цена` |
| `timeBudgetMillis` | 4000 | Лимит времени на один расчёт |
| `maxPatterns` | 3000 | Максимум паттернов в графе |
| `logPlans` | false | Писать планы в лог |

## Известные проблемы

- Окно подтверждения крафта показывает список вместо дерева AE2.
- Машины со случайными выходами планируются по тому, что записано в паттерне.
- Сеть B принимает заказы от шины только на свободный CPU. Если все заняты, заказ ждёт.
- Не связывайте две сети шинами в обе стороны на один и тот же предмет с включённым приоритетом: заказ зациклится.

## Сборка

Gradle запускается на JDK 25, мод компилируется JDK 8 (toolchain).

```sh
JAVA_HOME=<jdk-25> ./gradlew build
```

Запуск с `-Daegraph.selftest=true` строит тестовую сеть у спавна и прогоняет тесты в мире. Результат пишется в лог как `AEGRAPH SELFTEST: PASS/FAIL`.
